# Journal des décisions

Le brief demande qu'aucune règle ne soit décidée en silence. Ce journal consigne chaque choix
fait là où le brief ne tranchait pas, avec sa raison. Ils ont été arbitrés pour que l'expérience
soit la plus cohérente et la plus naturelle possible ; chacun peut être revu.

## Cadre général

| Sujet                   | Décision                                                                                                                         | Raison                                                                                                                                                                 |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Hébergement des données | Base SQLite rangée dans Netlify Blobs, au lieu de Netlify Database                                                               | Rester dans l'offre gratuite : Netlify Database est facturée au temps d'éveil, Blobs ne l'est pas. Choix validé pour 10 élèves au plus                                 |
| Langue du code          | Noms de code et de tables en anglais ; commentaires, messages et documentation en français                                       | Le code suit les usages des bibliothèques, tout ce qui se lit reste en français                                                                                        |
| Nom                     | « Grind up » à l'écran ; zip nommé `quetes-v<version>.zip`                                                                       | Le nom du zip est celui du brief                                                                                                                                       |
| Livraison               | Une demande de fusion par étape, fusionnée une fois ses tests au vert ; la version et son zip sont alors publiés automatiquement | Le brief demande une version publiée à la fin de chaque étape                                                                                                          |
| Emplacement des données | États-Unis, région par défaut de Netlify                                                                                         | L'offre gratuite ne permet pas de déplacer les fonctions ; placer le seul stockage en Europe ralentirait chaque action sans que le traitement y soit                   |
| Référencement           | Le site demande aux moteurs de recherche de ne pas le référencer                                                                 | C'est un outil privé entre un accompagnant et ses élèves                                                                                                               |
| Politique de sécurité   | Inscrite dans la page elle-même : seuls les scripts, styles et appels du site sont autorisés                                     | Elle accompagne le site quel que soit le mode de mise en ligne, et un test la contrôle dans le navigateur                                                              |
| Netlify en local        | Un module du projet appelle la fonction et sert le stockage, à la place de l'émulateur complet de Netlify                        | L'émulateur met environ 1,5 s par appel, le module quelques millisecondes ; la fonction telle que Netlify l'empaquette est vérifiée à part, à chaque demande de fusion |

## Ton et typographie

| Sujet              | Décision                                                                                             | Raison                                                                                         |
| ------------------ | ---------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| Tutoiement         | L'élève est tutoyé, l'admin vouvoyé ; les messages communs aux deux sont neutres                     | Naturel pour chaque public, sans mélange sur un même écran                                     |
| Écran de connexion | Tutoiement, puisqu'il est d'abord celui des élèves                                                   | Un seul ton par écran                                                                          |
| Ponctuation        | Espace insécable devant « ! », « ? », « : » et « ; », vérifiée par un test                           | Aucun signe seul en début de ligne sur un petit écran                                          |
| Messages d'erreur  | Fond rose pastel, texte bleu nuit, jamais d'emoji ni de texte rouge                                  | Section 8 : un emoji ne porte jamais seul une information, aucun dans les erreurs              |
| Apostrophe         | Typographique (’) dans tous les textes affichés, vérifiée par un test                                | Une seule forme partout à l'écran                                                              |
| Accords            | Les libellés évitent tout accord au masculin ou au féminin : « Compte actif », « Dernière activité » | Aucune donnée personnelle n'est collectée : le genre d'un élève est inconnu, et doit le rester |

## Comptes (étape 2)

| Sujet                         | Décision                                                                                                                                                  | Raison                                                                                                              |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Caractères du pseudo          | Lettres (accents compris), chiffres, tiret et tiret bas ; pas d'espace                                                                                    | Se saisit sans ambiguïté sur un téléphone                                                                           |
| Unicité du pseudo             | Sans tenir compte des majuscules ni des accents                                                                                                           | Plus strict que le brief : on ne peut pas imiter « Léa » avec « lea », et on se connecte sans retrouver ses accents |
| Pseudo en forme d'identifiant | Refusé                                                                                                                                                    | La connexion accepte l'identifiant ou le pseudo : l'un ne doit pas passer pour l'autre                              |
| Saisie de l'identifiant       | Minuscules, espaces et tiret oublié sont tolérés                                                                                                          | Un élève recopie son identifiant depuis un papier                                                                   |
| Connexion et inscription      | Un seul écran à deux onglets, « Connexion » et « Inscription » ; chacun a son adresse                                                                     | L'accompagnant peut transmettre directement l'adresse d'inscription                                                 |
| Code spécial                  | Replié sous « J'ai un code spécial »                                                                                                                      | Un élève ne voit pas un champ qui ne le concerne pas                                                                |
| Mauvais code spécial          | Aucun compte créé, message générique                                                                                                                      | Brief : jamais de compte admin, ni d'indice sur le code                                                             |
| Mot de passe                  | Un seul champ avec « Afficher », sans confirmation                                                                                                        | Usage courant sur téléphone ; l'admin peut le réinitialiser                                                         |
| Après l'inscription           | Un écran montre l'identifiant, le bouton pour le copier et la consigne de le noter                                                                        | Brief, section 2                                                                                                    |
| Avatar                        | Tiré au hasard dans la galerie à l'inscription ; l'élève le changera dans son profil                                                                      | Chaque élève a tout de suite un visage                                                                              |
| Durée de connexion            | 30 jours sans activité, prolongés à chaque visite ; pas de case « rester connecté »                                                                       | Un élève revient sur son téléphone sans ressaisir son mot de passe ; un choix de moins à l'écran                    |
| Dernière activité             | Enregistrée au plus une fois par heure                                                                                                                    | Suffisant pour repérer un élève inactif, sans écrire en base à chaque page                                          |
| Tentatives de connexion       | 10 échecs par quart d'heure et par adresse IP                                                                                                             | Freine les essais en série sans gêner un élève distrait                                                             |
| Inscriptions                  | 20 comptes par heure et par adresse IP                                                                                                                    | Laisse s'inscrire tout un groupe depuis le même réseau                                                              |
| Adresse IP                    | Seule son empreinte est conservée, le temps de la fenêtre de comptage                                                                                     | Le brief limite la collecte au pseudo, au mot de passe haché et à l'activité                                        |
| Mot de passe temporaire       | 12 caractères en trois blocs, affiché une seule fois à l'admin ; l'élève doit en choisir un nouveau à sa connexion suivante, sans ressaisir le temporaire | Même allure que l'identifiant, facile à dicter ; l'admin ne connaît jamais le mot de passe définitif                |
| Changement de mot de passe    | Garde l'appareil en cours connecté et déconnecte les autres                                                                                               | Un mot de passe changé doit fermer les sessions ouvertes ailleurs                                                   |
| Compte désactivé              | Déconnecté aussitôt ; le message ne s'affiche qu'avec le bon mot de passe                                                                                 | Rien n'indique à un tiers qu'un compte existe                                                                       |
| Suppression d'un élève        | Fenêtre de confirmation avec une case à cocher                                                                                                            | « Confirmation explicite » du brief, sans faire retaper le pseudo                                                   |
| Renommage                     | Par l'admin seulement ; l'identifiant ne change jamais                                                                                                    | Brief, sections 2 et 10                                                                                             |
| Plusieurs admins              | Possible : le code spécial est réutilisable                                                                                                               | Brief, section 14                                                                                                   |

| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |

| Liste des élèves          | Seul un compte désactivé porte une étiquette ; un compte actif n'en a pas                                                           | Signaler l'exception plutôt que répéter « actif » sur chaque ligne |
| Fenêtres de confirmation  | Boutons côte à côte sur ordinateur, empilés sur toute la largeur sur téléphone ; l'action qui fait avancer est toujours la dernière | Même ordre de lecture partout, boutons faciles à toucher           |
| Test de déploiement       | Déplacé de la page d'accueil à `/sante`, toujours public                                                                            | La page d'accueil est désormais l'application                      |

## Quêtes (étape 3)

| Sujet                      | Décision                                                                                                                                                                                                                 | Raison                                                                                                                                            |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| Vocabulaire                | « Deadline » à l'écran, comme dans le brief                                                                                                                                                                              | Le brief emploie ce mot partout, emojis compris (⏳ Deadline)                                                                                     |
| Brouillon                  | Peut être incomplet : seul le titre est requis. La publication exige une quête réalisable et dit quoi corriger                                                                                                           | L'admin enregistre son travail en cours sans être bloqué                                                                                          |
| Format proposé             | Suit la catégorie sur une quête neuve : Maths → réponse exacte, Mémorisation → cartes, Sport → déclaratif, Autre → réponse libre                                                                                         | Un choix de moins dans le cas courant ; l'admin reste libre                                                                                       |
| Seuil de réussite          | Réglable pour les trois formats corrigés automatiquement, 80 % par défaut                                                                                                                                                | Le brief ne le fixait pas pour les réponses exactes ; une seule règle pour les trois                                                              |
| Réponses acceptées         | Plusieurs par question, séparées par un point-virgule                                                                                                                                                                    | La virgule sert aux nombres décimaux                                                                                                              |
| Correction d'un QCM        | Une question est juste si tous les bons choix sont cochés, et eux seuls. L'élève sait s'il y a une ou plusieurs réponses à cocher                                                                                        | Usage courant des QCM                                                                                                                             |
| Test des cartes            | L'élève retrouve la réponse de chaque carte parmi celles des autres cartes (quatre propositions au plus)                                                                                                                 | Correction fiable quelle que soit la longueur des réponses, sans frappe sur téléphone ; le rappel par écrit existe déjà avec les réponses exactes |
| Cartes                     | Deux cartes au moins, aux réponses différentes                                                                                                                                                                           | Le test propose les réponses des autres cartes                                                                                                    |
| Après une tentative        | L'élève voit quelles réponses sont justes. Le corrigé n'apparaît qu'une fois la quête validée, pas quand les tentatives sont épuisées                                                                                    | L'admin peut redonner des tentatives : le corrigé les rendrait sans objet                                                                         |
| Passage à « En cours »     | Dès que l'élève ouvre la quête                                                                                                                                                                                           | Brief : « a ouvert ou commencé »                                                                                                                  |
| Calcul de l'XP             | Complet dès cette étape : bonus d'avance, bonus sans faute, moitié pour une quête rouverte                                                                                                                               | L'XP créditée est juste dès la première quête ; l'étape 4 l'affichera (journal, niveaux)                                                          |
| Cumul des bonus            | Ils s'additionnent : +20 %, pas +21 %. Le total fait foi, le dernier bonus absorbe l'arrondi                                                                                                                             | « Les bonus se cumulent, le total est arrondi »                                                                                                   |
| Quête rouverte             | Moitié de la récompense à l'origine, part réglable dans les Paramètres ; le bonus sans faute se calcule sur cette part. La réouverture vaut pour un élève, qui voit « Rouverte » et l'XP que la quête rapporte désormais | Brief, section 4 ; l'élève sait pourquoi la récompense a changé                                                                                   |
| Refus après la deadline    | Le refus propose de rouvrir la quête pour l'élève ; sans réouverture, elle expire                                                                                                                                        | Un refus demande de recommencer : encore faut-il que ce soit possible                                                                             |
| Quête modifiée             | Dès la première réponse d'un élève, seuls le titre, la consigne, l'image et la deadline changent encore                                                                                                                  | Brief : les questions et la récompense sont figées ; catégorie, difficulté, seuil et tentatives le sont avec elles                                |
| Nouvelle deadline          | Doit être dans le futur                                                                                                                                                                                                  | Une date passée ferait expirer la quête chez tout le monde                                                                                        |
| Élèves d'une quête publiée | On en ajoute depuis la fiche de la quête ; on n'en retire pas                                                                                                                                                            | Le brief ne prévoit que l'ajout                                                                                                                   |
| Élèves désactivés          | Ne reçoivent pas les quêtes données à « tous les élèves »                                                                                                                                                                | Un compte désactivé ne peut pas se connecter                                                                                                      |
| Archivage                  | Réversible. Une quête validée reste dans les quêtes terminées de l'élève ; les réalisations en attente quittent la file tant que la quête est archivée                                                                   | « L'XP déjà gagnée est conservée »                                                                                                                |
| Suppression                | Seuls les brouillons se suppriment                                                                                                                                                                                       | Une quête publiée porte de l'XP : elle s'archive                                                                                                  |
| Duplication                | Copie en brouillon, « (copie) » au titre, sans élèves, avec sa propre image                                                                                                                                              | Pour réassigner ou décliner une quête                                                                                                             |
| Image de la consigne       | Réduite dans le navigateur (1 600 px, JPEG), rangée à côté de la base, servie aux seuls admins et élèves de la quête                                                                                                     | Envoi rapide depuis un téléphone ; la base reste légère                                                                                           |
| Compte à rebours           | La formule change avec l'urgence : « Encore… », « Plus que… », « Urgent : plus que… »                                                                                                                                    | Section 8 : une couleur n'est jamais le seul signal                                                                                               |
| Onglet « À faire »         | Regroupe À faire, En cours et Refusée                                                                                                                                                                                    | Trois états où c'est à l'élève d'agir                                                                                                             |
| Carte d'une quête          | Un seul emoji, celui de la catégorie ; récompense, statut et délai sont écrits                                                                                                                                           | Section 8 : un seul emoji par carte                                                                                                               |
| File de validation         | Toutes les réalisations sont dépliées ; « Valider » agit en un geste, « Refuser » demande un commentaire                                                                                                                 | Le geste le plus fréquent est le plus court                                                                                                       |
| Tableau de bord de l'élève | Montre déjà ses quêtes à faire, la deadline la plus proche d'abord                                                                                                                                                       | L'écran ne peut pas dire « aucune quête » quand il y en a                                                                                         |

## Progression (étape 4)

| Sujet                       | Décision                                                                                                                                                       | Raison                                                                                 |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| Jour d'une validation       | Pour la série, c'est le jour de la soumission qui compte quand l'admin valide plus tard                                                                        | « La date de soumission fait foi » : la série ne dépend pas du moment où l'admin passe |
| Jour neutre                 | Un jour où l'élève n'avait rien à faire ne casse pas la série : aucune quête, ou seulement des quêtes soumises, expirées, archivées ou sans tentative restante | Brief : « un jour sans aucune quête assignée en cours ne casse pas la série »          |
| Journée en cours            | Ne rien avoir validé aujourd'hui ne casse pas la série avant minuit, heure de Paris                                                                            | La journée n'est pas finie                                                             |
| Badges                      | Attribués à la validation, jamais retirés, même si la validation est annulée ensuite                                                                           | « Un badge ne s'obtient qu'une fois »                                                  |
| Badges à débloquer          | Montrés avec leur condition et l'avancement de l'élève (« Tu en es à 4 sur 10 »)                                                                               | Donner envie de les obtenir                                                            |
| Badge Podium                | Affiché dès maintenant, attribué à partir de l'étape 5                                                                                                         | Il dépend du leaderboard                                                               |
| Annonce d'une validation    | Une fenêtre fête chaque quête validée : XP gagnée, passage de niveau, nouveaux badges. Si l'admin a validé en l'absence de l'élève, elle l'attend à son retour | Brief : un retour visuel à chaque moment clé                                           |
| Animations                  | Moins d'une seconde ; coupées quand l'appareil demande de les réduire, le gain s'affiche alors d'emblée                                                        | Brief, section 6                                                                       |
| XP négative                 | Un ajustement peut faire passer l'XP totale sous zéro ; le niveau reste à 1                                                                                    | Le journal dit la vérité, le niveau ne descend pas sous 1                              |
| Ajustement manuel           | De 1 à 10 000 XP, ajoutés ou retirés, avec un motif que l'élève lit dans son historique. Ce n'est pas une mission                                              | Brief : motif obligatoire                                                              |
| Annulation d'une validation | Depuis la fiche de l'élève, avec un commentaire facultatif. Tout ce que la validation avait crédité est retiré, bonus compris                                  | Brief, section 10                                                                      |
| Tableau de bord             | En-tête au dégradé « Ciel », niveau et barre d'XP, série, missions, quêtes à faire, dernières récompenses. Le rang arrivera avec le leaderboard                | Brief, section 6                                                                       |
| Galerie d'avatars           | Repliée sous l'identité, dans le profil ; le choix est enregistré aussitôt                                                                                     | Les badges et l'historique restent en haut de l'écran                                  |
| Historique d'XP             | Les cinq dernières lignes, puis « Voir tout l'historique »                                                                                                     | L'écran reste court sur téléphone                                                      |
| Fraîcheur des données       | Quêtes, progression, validations et élèves sont relus à chaque ouverture d'écran                                                                               | Ce qu'un autre a changé se voit sans recharger la page                                 |

## Leaderboard et bots (étape 5)

| Sujet                        | Décision                                                                                                                                                                                                  | Raison                                                                                                  |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| Participants sans activité   | Seuls ceux qui ont une mission ou de l'XP sur la période reçoivent un rang ; les autres suivent sans rang, par ordre alphabétique                                                                         | Personne ne monte sur le podium d'une semaine où il n'a rien fait                                       |
| Égalité parfaite             | Deux participants à égalité de missions, d'XP et de date partagent le même rang                                                                                                                           | Aucun critère ne les départage                                                                          |
| Validation annulée           | La mission n'est plus comptée, même dans la semaine où elle avait été gagnée ; l'XP retirée est datée du jour de l'annulation                                                                             | Brief : « la mission n'est plus comptée » ; le journal, lui, ne se réécrit pas                          |
| Flèche de mouvement          | Compare le classement à celui de la veille à minuit, heure de Paris, sur la même période. Pas de flèche le premier jour d'une période, ni à l'entrée au classement                                        | « Depuis la veille »                                                                                    |
| Niveau affiché               | Celui de l'XP totale, quelle que soit la période                                                                                                                                                          | Le niveau ne dépend pas de la période regardée                                                          |
| Ligne de l'élève             | Cernée et marquée « Toi » ; elle reste à l'écran quand la liste défile                                                                                                                                    | Brief : visible même s'il est loin dans la liste                                                        |
| Leaderboard de l'admin       | Affiché sur l'écran Bots, avec l'étiquette « Bot »                                                                                                                                                        | Le brief lui donne le droit de le voir sans lui donner d'entrée de menu ; c'est là qu'il règle les bots |
| Étiquette « Bot »            | Réglée dans les Paramètres, comme le prévoit le brief ; l'écran Bots rappelle le réglage et y mène. Désactivée, rien ne distingue un bot : même galerie d'avatars, mêmes règles de pseudo                 | Brief : réglage désactivé par défaut ; un seul endroit pour un réglage                                  |
| Missions d'un bot régulier   | Datées de l'heure tirée au sort, pas de l'heure où le classement est demandé                                                                                                                              | Le classement et ses égalités restent justes, même consulté tard                                        |
| Bot créé en cours de semaine | Seules les missions tirées après sa création comptent                                                                                                                                                     | Il ne rattrape pas un passé qu'il n'a pas eu                                                            |
| Semaines sans visite         | Rattrapées à la première demande de classement, douze semaines au plus                                                                                                                                    | Aucune tâche planifiée : les bots « progressent seuls » malgré tout                                     |
| Bot en pause                 | Garde sa place, ne progresse plus ; à la reprise, rien n'est rattrapé                                                                                                                                     | Une pause n'est pas un retard à combler                                                                 |
| Bot adaptatif                | Vise, sur le classement de la semaine, une mission de plus que le premier élève, la médiane, ou une de moins que le dernier. Une mission par heure au plus, entre 8 h et 21 h                             | Brief : réévalué au plus une fois par heure, par petites étapes                                         |
| Plafond                      | Activé par défaut. Le bot reste au moins une mission derrière le meilleur élève, en missions comme en XP, sur la semaine, le mois et depuis toujours ; une mission qui le ferait passer devant est perdue | « Ne dépasse jamais le premier élève réel », quel que soit le tri                                       |
| XP d'une mission de bot      | Tirée dans le barème des difficultés ; répartition par défaut : 40 % facile, 40 % moyen, 15 % difficile, 5 % épique                                                                                       | Proche de ce que gagnent les élèves                                                                     |
| Ajustement d'un bot          | De 20 missions et de 10 000 XP au plus, en plus ou en moins                                                                                                                                               | Assez pour corriger, pas pour se tromper d'un zéro                                                      |
| Badge Podium                 | Attribué à la première demande de classement après la fin d'une semaine, bots comptés ; huit semaines rattrapées au plus                                                                                  | Aucune tâche planifiée ; un élève quatrième derrière un bot n'est pas sur le podium                     |

## Finitions (étape 6)

| Sujet                       | Décision                                                                                                                                                                                                                    | Raison                                                                                    |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| Paramètres                  | Un seul formulaire, enregistré d'un geste. Un bouton remet les valeurs d'origine dans le formulaire, sans les enregistrer                                                                                                   | Tout s'applique en une fois ; rien ne change par mégarde                                  |
| Barème d'XP                 | Pré-remplit la récompense d'une nouvelle quête et sert à tirer l'XP des missions des bots. Les quêtes déjà créées gardent leur récompense                                                                                   | Brief : récompense « pré-remplie selon la difficulté, modifiable »                        |
| Bonus                       | De 0 à 100 %. Un changement vaut pour les validations suivantes ; l'XP déjà gagnée n'est jamais recalculée                                                                                                                  | Le journal d'XP ne se réécrit pas                                                         |
| Avance de 24 h              | Le délai qui donne droit au bonus d'avance n'est pas réglable                                                                                                                                                               | Le brief ne rend réglables que des montants ; ce délai est annoncé aux élèves             |
| Niveaux                     | La formule des niveaux n'est pas réglable                                                                                                                                                                                   | La changer déplacerait d'un coup le niveau de tous les élèves                             |
| Nouvelles quêtes            | Les paramètres proposent le seuil de réussite et le nombre de tentatives ; chaque quête garde ensuite les siens                                                                                                             | « Seuils de réussite par défaut » ; les tentatives suivent la même logique                |
| Vue d'ensemble              | Trois chiffres qui mènent chacun à leur écran (élèves actifs, quêtes en cours, réalisations à valider), puis la liste des quêtes qui expirent dans les 48 h et celle des élèves inactifs depuis 7 jours                     | Un chiffre dit combien, une liste dit lesquels                                            |
| Élève actif                 | Un compte qui n'est pas désactivé                                                                                                                                                                                           | Le même sens que dans la liste des élèves                                                 |
| Quête en cours              | Quête publiée qu'un élève actif au moins doit encore finir, ou dont il attend la validation                                                                                                                                 | Une quête finie ou expirée pour tous ne demande plus rien                                 |
| Quête qui expire            | Deadline dans les 48 h, pour un élève au moins qui ne l'a ni finie ni soumise                                                                                                                                               | Une réalisation soumise n'expire plus                                                     |
| Élève inactif               | Compte actif sans visite depuis 7 jours ; la dernière visite est notée à l'heure près                                                                                                                                       | Brief : « inactifs depuis 7 jours »                                                       |
| Export CSV                  | Quatre fichiers : élèves, quêtes, réalisations, journal d'XP. Ni mot de passe ni identifiant interne                                                                                                                        | Un tableau par fichier ; rien que l'admin ne voie déjà à l'écran                          |
| Format du CSV               | Point-virgule, UTF-8 avec marque d'en-tête, dates à l'heure de Paris                                                                                                                                                        | S'ouvre d'un double clic dans un tableur réglé en français                                |
| Formules dans le CSV        | Un texte qui commence par =, +, - ou @ est précédé d'une apostrophe                                                                                                                                                         | Un pseudo ou un titre ne doit pas devenir une formule dans le tableur                     |

## Bibliothèque d'exercices (version 1.1)

| Sujet                         | Décision                                                                                                                                                                                                                                                                                      | Raison                                                                                                                                              |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Plan d'un exercice            | Toujours le même : un bref rappel du cours, un exemple expliqué de la méthode, des questions pour pratiquer, la correction détaillée de chaque question                                                                                                                                       | La demande : « un bref rappel du cours, un exemple expliqué, puis l'exercice »                                                                      |
| Rappel du cours et exemple    | Deux textes facultatifs de toute quête, mis en forme comme une consigne et montrés avant elle. L'élève les lit dès qu'il ouvre la quête                                                                                                                                                       | Ils préparent la quête et ne contiennent aucune réponse attendue ; l'admin peut en écrire dans ses propres quêtes                                   |
| Rappel et exemple modifiables | Ils restent modifiables après la première réponse d'un élève, comme le titre et la consigne                                                                                                                                                                                                   | Ils ne changent ni les questions ni la récompense                                                                                                   |
| Correction détaillée          | Un texte facultatif par question (réponse exacte, QCM), mis en forme comme une consigne. Une carte de mémorisation n'en a pas : elle se corrige par son verso                                                                                                                                 | Un seul champ, que l'admin sait déjà remplir                                                                                                        |
| Moment de la correction       | Montrée avec le corrigé, une fois la quête validée ; jamais après une tentative manquée, ni quand les tentatives sont épuisées                                                                                                                                                                | Elle donne la réponse : même règle que les réponses attendues (étape 3)                                                                             |
| Affichage de la correction    | Repliée sous la bonne réponse ; celle d'une réponse à revoir est déjà dépliée                                                                                                                                                                                                                 | L'élève lit d'abord ce qu'il a manqué, et l'écran reste court                                                                                       |
| Correction figée              | Figée avec sa question dès qu'un élève a répondu                                                                                                                                                                                                                                              | Même règle que les questions (étape 3)                                                                                                              |
| Après une réponse             | Le résultat (verdict, ou quête validée) est ramené en haut de l'écran                                                                                                                                                                                                                         | L'élève vient de toucher le bouton du bas de la quête, le résultat s'affiche plus haut                                                              |
| Bibliothèque                  | Des exercices prêts à l'emploi, livrés avec l'application et servis à l'admin seulement. En choisir un ouvre une nouvelle quête déjà remplie, sans rien enregistrer                                                                                                                           | L'admin relit, modifie s'il le veut, choisit ses élèves et publie, dans le formulaire qu'il connaît                                                 |
| Accès à la bibliothèque       | Un bouton de l'écran Quêtes, pas une entrée de menu                                                                                                                                                                                                                                           | Le brief fixe les six écrans de l'admin ; la bibliothèque sert à créer une quête                                                                    |
| Rangement                     | Par thème du programme, dans l'ordre où on les étudie ; un filtre par thème et une recherche sans accents ni majuscules                                                                                                                                                                       | Retrouver une notion parmi une trentaine d'exercices                                                                                                |
| Programme                     | Le programme national de la classe de 3e (cycle 4). Les exercices sur les identités remarquables vont jusqu'aux carrés (a + b)² et (a − b)²                                                                                                                                                   | Demande de l'accompagnant. Le nom de l'établissement de l'élève n'est transmis à aucun service extérieur : aucune recherche n'est faite à son sujet |
| Réglages d'un exercice        | Sa récompense suit sa difficulté dans le barème ; le seuil de réussite et les tentatives sont ceux des Paramètres                                                                                                                                                                             | Un exercice ne contourne pas les réglages de l'admin                                                                                                |
| QCM ou réponse à saisir       | Un nombre simple se saisit ; tout le reste (expression littérale, fraction, phrase) se choisit dans un QCM à une seule bonne réponse, dont chaque mauvais choix est une erreur courante que la correction nomme                                                                               | Sur un téléphone, saisir « x² − 10x + 25 » sans faute de frappe est incertain : une réponse juste refusée découragerait l'élève                     |
| Géométrie sans figure         | Chaque situation est décrite par son énoncé ; l'exemple commence par un schéma à main levée                                                                                                                                                                                                   | Une quête n'a qu'une image, choisie par l'admin ; savoir dessiner la figure fait partie de la méthode                                               |
| Écriture des calculs          | Carré « ² », signe moins « − », signe « × », fraction 3/4 ; la typographie est appliquée automatiquement, et les parenthèses courtes ne se coupent pas en fin de ligne                                                                                                                        | Lisible sur un petit écran, sans confusion entre la lettre x et la multiplication                                                                   |
| Ton                           | L'élève est tutoyé dans les énoncés et les rappels ; les exemples et les corrections expliquent avec « on »                                                                                                                                                                                   | Le ton de l'espace élève                                                                                                                            |
| Vérification du contenu       | Des tests relisent chaque exercice (plan, longueurs, typographie, bonne réponse énoncée, mauvais choix tous commentés) et recalculent chaque égalité qu'ils savent lire                                                                                                                       | Une erreur dans un corrigé est la plus coûteuse des erreurs                                                                                         |
| Réponse saisie                | L'élève écrit le nombre seul. Sa réponse reste juste s'il l'habille comme l'énoncé y invite : avec l'unité demandée (« 5 cm »), ce que l'on compte (« 12 séances ») ou l'inconnue (« x = 8 »). Un même nombre est reconnu sous toutes ses écritures, seul ou à côté d'une unité (« 85,00 € ») | Une réponse juste, refusée pour sa forme, découragerait l'élève                                                                                     |
| Relecture des exercices       | Chaque exercice a été relu par un second correcteur, qui a refait chaque question à partir du seul énoncé avant de lire le corrigé, puis refait le calcul de chaque erreur décrite                                                                                                            | Les tests ne recalculent que les égalités : un énoncé ambigu ou un piège mal expliqué ne se voient qu'à la lecture                                  |
| Catalogue                     | Le README liste les exercices ; un test compare ce tableau aux exercices livrés                                                                                                                                                                                                               | Un catalogue écrit à la main finit par mentir                                                                                                       |
